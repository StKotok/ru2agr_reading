# CLAUDE.md

Этот файл — мостик. Все правила ИИ-кодинга живут в [AGENTS.md](AGENTS.md) —
прочитай и соблюдай его до любого изменения кода. Продукт, архитектура и план
задач — в [DEVELOPMENT.md](DEVELOPMENT.md) (разделы 3–5).

Быстрый гейт после каждого изменения (после задачи 0.1, когда появится
`package.json`):

```bash
npm test
```

Полный гейт перед «готово» и перед коммитом:

```bash
npm run build
```

Пока `package.json` нет — проверка только ручная: `npx serve .` (или
`python3 -m http.server`) и открыть приложение в браузере.
