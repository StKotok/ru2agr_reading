## Рекомендованный набор для англоязычных пользователей

### Основной перевод для пользователей

**BSB — Berean Standard Bible**

Лучший баланс:

* современный понятный английский;
* достаточно близок к греческому тексту;
* хорошо подходит для обучения;
* public domain;
* можно хранить офлайн и использовать коммерчески.

### Дополнительные переводы для пользователей

1. **OEB — Open English Bible**
   Современный независимый перевод. Полезен для сравнения формулировок.

2. **ASV 1901 — American Standard Version**
   Более буквальный, но язык устаревший. Полезен продвинутым ученикам.

3. **WEB — World English Bible**
   Понятный современный английский, но местами расходится с SBLGNT из-за ориентации на Majority Text. Подключать как дополнительный, не как эталонный.

### Для процесса выравнивания

Использовать в таком порядке:

1. **BSB** — основной источник английского соответствия.
2. **ASV** — проверка более буквальной передачи греческих конструкций.
3. **OEB** — независимая проверка смысла и современной формулировки.
4. **ULT — unfoldingWord Literal Text** — технический помощник для сложных мест.

`ULT` полезен именно внутри pipeline, потому что старается прозрачно отражать структуру оригинала.

### Что показывать пользователям

Показывать:

```text
BSB — основной
OEB — дополнительный современный
ASV — дополнительный буквальный
WEB — опциональный
```

Оптимальный интерфейс:

```text
По умолчанию: BSB
Другие переводы:
— OEB
— ASV
— WEB
```

### Что не показывать пользователям по умолчанию

* **ULT** — слишком технический и не предназначен прежде всего для естественного чтения.
* **KJV** — архаичный язык, Textus Receptus и дополнительные сложности для глобального распространения.
* **LSV** — специфический английский, менее авторитетный и менее удобный новичкам.

### Итог

```text
Для чтения:
BSB + OEB + ASV
опционально WEB

Для alignment:
BSB + ASV + OEB + ULT

Внутренний технический перевод:
ULT

Главный пользовательский перевод:
BSB
```

## Рекомендованный набор для русскоязычных пользователей

### Основной перевод для пользователей

**Синодальный перевод**

Лучший выбор для этого приложения:

* знаком большинству русскоязычных христиан;
* достаточно близок к структуре греческого текста;
* исторический текст находится в public domain;
* доступна свободная цифровая редакция, которую можно хранить офлайн и использовать коммерчески.

Важно зафиксировать конкретный источник цифрового текста и не смешивать его незаметно с редакциями других издателей.

### Дополнительные переводы для пользователей

1. **СРП — Современный русский перевод РБО**
   Современный понятный русский язык. Полезен для сравнения смысла и естественной передачи текста. Для полного встраивания в приложение нужно разрешение РБО: без него разрешено лишь ограниченное цитирование.

2. **Перевод Андрея Десницкого**
   Современный авторский перевод с серьёзной филологической основой. Полезен для сравнения интерпретаций и сложных мест. Некоммерческое цитирование разрешено с указанием авторства, но коммерческое использование требует письменного разрешения автора.

3. **Перевод епископа Кассиана**
   Более буквальный перевод Нового Завета, основанный на критическом греческом тексте. Особенно полезен продвинутым ученикам. Права и разрешение на распространение нужно согласовать с правообладателем.

### Для процесса выравнивания

Использовать в таком порядке:

1. **Синодальный перевод** — основной целевой русский текст приложения.
2. **Перевод Кассиана** — проверка более буквального соответствия критическому греческому тексту.
3. **Перевод Десницкого** — независимая филологическая проверка смысла сложных мест.
4. **СРП РБО** — проверка естественной современной передачи греческой конструкции.

Перевод Кассиана особенно полезен внутри pipeline, поскольку он стремится к буквальности и основан на критическом тексте НЗ. Однако окончательное выравнивание Синодального нужно выполнять непосредственно с SBLGNT/MACULA, а не через другой русский перевод.

### Что показывать пользователям

Показывать:

```text
Синодальный — основной
СРП РБО — дополнительный современный
Десницкий — дополнительный научно-авторский
Кассиан — дополнительный буквальный
```

Оптимальный интерфейс:

```text
По умолчанию: Синодальный

Другие переводы:
— Современный русский перевод РБО
— Перевод Андрея Десницкого
— Перевод епископа Кассиана
```

СРП, Десницкого и Кассиана подключать после получения необходимых разрешений.

### Что не показывать пользователям по умолчанию

* **Автоматический русский подстрочник** — это технический результат alignment, а не полноценный перевод Библии.
* **Машинный перевод с греческого** — может создавать ложное впечатление точности и авторитетности.
* **НРП — Новый русский перевод Biblica** — понятен для чтения, но менее прозрачен для пословного изучения греческого и требует разрешения правообладателя.
* **Неизвестные интернет-редакции Синодального** — могут содержать незафиксированные исправления, современную редактуру и неясные права на конкретную цифровую версию.

### Итог

```text
Для чтения:
Синодальный
после получения разрешений:
СРП РБО + Десницкий + Кассиан

Для alignment:
Синодальный + Кассиан + Десницкий + СРП РБО

Внутренний технический текст:
собственный русский подстрочник,
сформированный из alignment,
но не показываемый как перевод Библии

Главный пользовательский перевод:
Синодальный
```
