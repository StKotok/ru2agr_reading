## 1. Greek New Testament Text

### 1.1 Primary Text (Base Layer)

**Требование:** наиболее авторитетный критический текст греческого Нового Завета.

**Кандидаты (по убыванию авторитетности):**

| Text | Authority | License | Status |
|------|-----------|---------|--------|
| **NA28** (Nestle-Aland, 28th ed.) | ★★★★★ Академический стандарт. Используется в семинариях, переводах, научных работах. Идентичен UBS5 по тексту, отличается аппаратом. | Коммерческая (Deutsche Bibelgesellschaft / German Bible Society) | Требуется лицензия |
| **UBS5** (United Bible Societies, 5th ed.) | ★★★★★ Тот же текст, что NA28; другой критический аппарат (для переводчиков). | Коммерческая (UBS) | Требуется лицензия |
| **SBLGNT** (SBL Greek New Testament) | ★★★★☆ Свободный текст, очень близок к NA27. Редактировал Michael W. Holmes. Используется в проекте сейчас. | **CC-BY 4.0** (SBL + Logos) | ✅ Уже есть |
| **Byzantine / Majority Text** | ★★★☆☆ Текст большинства рукописей. Используется Православной церковью. | Различается | Не приоритет |
| **Textus Receptus** (TR, 1550/1894) | ★★☆☆☆ Традиционный текст (KJV). Научно устарел. | Public domain | Не приоритет |

**Рекомендация:** SBLGNT уже в проекте и покрывает 99% потребностей. NA28 имеет смысл запрашивать только если Deutsche Bibelgesellschaft готова дать лицензию на встраивание в приложение. Различия SBLGNT ↔ NA28 — около 35–40 разночтений на весь НЗ (менее 0.03%), большинство из которых не затрагивают лексику.

**Необходимый формат данных:**
- Токены по книгам/главам/стихам
- Для каждого токена: поверхностная форма (ὁ, λόγον, ἀγάπῃ...)
- Идентификатор «книга:глава:стих:позиция»
- Покрытие: все 27 книг НЗ (~7 957 стихов, ~138 000 токенов)

3. Какая атрибуция требуется (в титрах, в интерфейсе)?
4. Есть ли ограничения на коммерческое распространение приложения?

### 1.2 Pronunciation Data

**Требование:** правильное чтение с правильным произношением для каждого слова/формы.

**Системы произношения:**

| System | Description | Audience | Pros | Cons |
|--------|------------|----------|------|------|
| **Erasmian** | Учебное приближение, основано на работах Эразма Роттердамского (XVI в.). η = [eɪ], υ = [ju], θ = [θ] как в англ. 'thin' | Студенты семинарий, русскоязычные новички | Привычно для русскоязычных, простая система, много учебных материалов | Не историческая; разные варианты в разных странах |
| **Modern Greek** | Современное греческое произношение. η/ι/υ/ει/οι = [i], β = [v], γ = [ɣ]~[ʝ] | Греческая православная традиция | Живое произношение, носители языка | Много звуковых слияний (7 букв/диграфов → [i]), не различает долготу |
| **Reconstructed Koine** | Историческая реконструкция койне I в. н.э. η = [e̝], υ = [y], οι = [ø] | Академическая среда | Наиболее близко к реальному произношению апостольского времени | Нестабильно (разные реконструкции), непривычно для новичков |

**Текущий статус в проекте:** «простое учебное приближение для русскоязычного новичка (эразмово чтение)» — DEVELOPMENT_1.md раздел 1.

**Требование:** **два варианта произношения:**

1. **Erasmian (учебное)** — уже заложено в проекте: 24 буквы в `alphabet.json`, поле `sound`. Требуется расширить до произношения каждого слова.
2. **Modern Greek (живое)** — запись носителем или TTS-движок. Произношение слов, а не отдельных букв.

## 2. Lexical Data (Top-1000 Lemmas)

### 2.1 Core Requirement

**Объём:** топ-1000 лемм Нового Завета по частоте (покрывают ~93% текста).

**Для каждой леммы требуется:**

| # | Поле | Описание                                     | Пример | Приоритет |
|---|------|----------------------------------------------|--------|-----------|

| 4 | **pos** | Часть речи + грамматический род/тип          | `сущ., муж. род, 2-е скл.` | 🔴 Критический |
| 5 | **morph** | Полная морфологическая парадигма (все формы) | `λόγος, λόγου, λόγῳ, λόγον, λόγοι, λόγων, λόγοις, λόγους` | 🟡 Важный |

### 2.2 Grammar Data

**Для леммы (словарная информация):**
- Часть речи (существительное, глагол, прилагательное, предлог, союз, частица, местоимение, наречие, числительное, артикль, междометие)
- Для существительных: род (муж/жен/сред), тип склонения
- Для глаголов: тип (тематический/атематический), переходность
- Для прилагательных: тип (2-го/3-го склонения, двух/трёх окончаний)

**Для формы (морфологический разбор):**
- Код Робинсона (напр. `V-PAI-3S` = глагол, настоящее, актив, индикатив, 3-е лицо, ед. число)
- Расшифровка кода на русском («глагол, наст. время, активный залог, изъявительное накл., 3-е лицо, ед. ч.»)

### 3.2 Alignment Strategy

**Требование:** для каждого из топ-1000 слов выравнивание на каждый подключенный перевод.

**Метод выравнивания (по убыванию качества):**

| Method | Accuracy | Cost | Notes |
|--------|----------|------|-------|
| **По номерам Стронга** | 85–95% | Низкий | Уже работает в проекте (Syn ↔ SBLGNT). Требует, чтобы перевод был размерен по Стронгу. |
| **LLM-выравнивание** | 90–98% | Средний (~$5–15 за перевод) | Claude/Opus с контекстом стиха и Strong-подсказками. Требует верификации. |
| **Ручное выравнивание** | 98–99% | Высокий | Эталонное качество, трудозатратно. |
| **Гибрид: Strong → LLM → ручная верификация** | 97–99% | Средний | Рекомендуемый подход. |

**Рекомендуемый процесс для каждого нового перевода:**

```
1. Получить текст перевода (лицензия)
2. Разметить стихи (book/chapter/verse)
3. Для каждого стиха:
   a. Сопоставить слова перевода греческим токенам через Strong (автоматически)
   b. Где нет Strong или неоднозначность — LLM (Claude Opus) с промптом:
      «Дан греческий стих с номерами Стронга и русский/английский перевод.
       Сопоставь каждому греческому слову переводное слово по смыслу и Стронгу.
       Для слов без прямого соответствия укажи 'none'.»
   c. Верифицировать выборочно (ручная проверка 2–3% стихов)
4. Сохранить alignment в формате: { bookId, verses: { "1:1": [{gr: N, tr: M}, ...] } }
```

**Формат данных выравнивания (на каждый перевод):**

```json
{
  "id": "john",
  "translation": "kjv",
  "verses": {
    "1:1": [
      { "gr": 0, "tr": 0, "strong": 1722, "confidence": "strong" },
      { "gr": 1, "tr": 1, "strong": 746, "confidence": "strong" },
      { "gr": 2, "tr": 2, "strong": 3588, "confidence": "strong" }
    ]
  }
}
```

Поле `confidence`: `"strong"` (совпали Strong), `"llm"` (LLM-сопоставление), `"manual"` (ручная верификация), `"none"` (нет соответствия).

### 7.2 Pronunciation Engine (Erasmian)

Наиболее простой путь — не искать готовый источник, а построить движок правил:

```js
// src/engine/pronunciation.js — концепт
const ERASMIAN = {
  'α': { ipa: 'a', ru: 'а' },
  'β': { ipa: 'b', ru: 'б' },
  'γ': { ipa: 'ɡ', ru: 'г' },
  // ... все 24 буквы + диграфы
};

function erasmianIPA(word) {
  // 1. Разбить на слоги по правилам древнегреческого
  // 2. Применить правила для каждой буквы
  // 3. Найти ударение (accent) → поставить stress
  // 4. Применить сандхи (γ перед γ/κ/χ/ξ → ŋ)
  return { ipa, russian, syllables };
}
```

**Преимущество:** не требует лицензии, полностью контролируется, можно итеративно улучшать.
