# H1 · Тонкая полоска — лаконичная линия прогресса

## Источник

Прототип: `docs/ru2gr_design-example/Греческая_читалка.dc.html`, функция `chipH1()` (строки 902–916).

## Что делаем

Добавляем тонкую горизонтальную полоску прогресса (3px) в существующий чип состояния греческого слоя (`mode-widget-chip` в верхней панели экрана чтения). Полоска визуализирует интенсивность замены букв (0–100%).

## Спецификация чипа

### Размеры и форма

| Свойство | Значение |
|----------|----------|
| border-radius | 8px |
| padding | 6px 12px |
| min-height | 32px |
| font-size | 0.8125rem (13px) |
| font-weight | 600 |
| line-height | 1 |
| background | var(--surface-card) |
| border | 1px solid var(--border) |
| align-items | center |

### Типографика внутри чипа

| Элемент | Шрифт | Размер | Цвет |
|---------|-------|--------|------|
| α (альфа) | var(--font-greek) | 18px | var(--greek) |
| N% (процент) | sans | 12px | var(--text) |
| · (разделитель) | sans | — | var(--muted), margin 0 4px |
| λέγω (слово) | var(--font-greek) | 14px | var(--greek-word) |
| N (счётчик) | sans | 12px | var(--muted) |

### Полоска прогресса

| Свойство | Значение |
|----------|----------|
| Структура | column flex, align-items: stretch |
| Высота | 3px |
| Скругление | 3px |
| Отступ от текста | margin-top: 4px |
| Трек | var(--greek-bar-track) |
| Заливка | var(--greek) |
| Ширина заливки | {intensity}% |
| Анимация | transition: width 0.2s ease |

### Состояния отображения

| Состояние | Текст | Полоска |
|-----------|-------|---------|
| Греческий слой выключен | «Рус» | нет |
| Греческий оригинал | «Греч» на тёмном фоне | нет |
| Только буквы (αN%) | α + N% | да |
| Буквы + слова (αN% · слово N) | полный текст | да |
| Буквы + словарь без данных (αN% · —) | полный текст | да |

## Новый дизайн-токен

Добавить в `assets/styles/tokens.css`:

```css
:root, [data-theme="light"] {
  --greek-bar-track: rgba(38, 78, 131, 0.15);
}
[data-theme="dark"] {
  --greek-bar-track: rgba(123, 163, 204, 0.15);
}
```

- Попап настроек (mode-widget-popup) — слайдер и мини-чип без изменений

- Логика store, настроек, словаря
- Все состояния и переходы между ними
