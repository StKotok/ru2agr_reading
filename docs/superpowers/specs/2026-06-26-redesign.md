# Редизайн — полный визуальный редизайн под прототип

> Источник дизайна: `docs/ru2gr_design-example/project/`.  
> Цель: привести UI приложения в соответствие с дизайн-прототипом, сохранив всю
> существующую логику (движок, загрузчики, state, IndexedDB, PWA).

## Архитектурные границы

**Меняется:** `src/ui/**`, `assets/styles/**` — визуал и структура DOM.  
**НЕ меняется:** `src/engine/**`, `src/data/**`, `src/state/**`, `src/storage/**`,
`src/router.js`, `vite.config.js`, PWA, IndexedDB-схема.

## Подход: слоями

Каждый слой — отдельный коммит. Порядок: фундамент → каркас → комнаты.

## Слой 1 — Токены + CSS-фундамент

### Цветовая система (12 тем прототипа)

Заменить `assets/styles/tokens.css`: все custom properties на токены из `ru2gr-tokens.js`:

| Токен | Назначение |
|-------|-----------|
| `--paper` | основной фон |
| `--paper2` / `--sidebar` | фон боковой панели |
| `--read` | фон области чтения |
| `--titlebar` | фон заголовка |
| `--ink` | основной текст |
| `--inkSoft` | вторичный текст |
| `--muted` | приглушённый текст |
| `--muted2` | ещё более приглушённый |
| `--line` | границы (ink 10%) |
| `--line2` | границы жирные (ink 18%) |
| `--blue` | греческие буквы |
| `--blueBg`, `--blueTx` | фон/текст для blue |
| `--terra` | греческие слова |
| `--terraSoft` | фон для terra |
| `--green`, `--greenDk`, `--greenBg` | действия/позитив |
| `--overlayDimBase`, `--overlayDimAlpha` | затемнение фона |
| `--toastBg`, `--toastTx` | тост-уведомления |
| `--shadowBase` + отдельные альфы | тени |

Темы — русские названия (Пергамент, Сепия, … Уголь). 9 светлых + 3 тёмных.

### Типографика

- Основной шрифт чтения: Gentium Plus (serif), 18.5px, line-height 1.72
- UI-шрифт: Source Sans 3 (sans-serif), 11–16px — **добавить через Google Fonts**
- Греческий оригинал: Gentium Plus 20px, line-height 1.55
- Моноширинный: системный (для Strong's и тех. данных)

### Пространственные токены

- `--radius`: 10px, `--radius-sm`: 7px, `--radius-lg`: 16px
- `--content-width`: 700px (макс. ширина текста)
- `--nav-width`: 236px (десктопная навигация)
- `--insp-width`: 364px (инспектор)

### Адаптация `app.css`

- Глобальный сброс (`box-sizing: border-box`)
- Стили скроллбара (нулевая ширина для чтения)
- Фокус: `:focus-visible` с outline
- Переопределение базовых элементов под новые токены

### Инварианты

- 12 тем переключаются через `data-theme`
- SVG-иконки используют `currentColor`
- Контраст текста ≥ 4.5:1 во всех темах (проверить)

## Слой 3 — Экраны

### 3a — Читалка (`reading.js`)

**Top header** — из слоя 2 (top-bar.js).

**Текст**:
- Стихи: Gentium Plus 18.5px, цвет `--ink`, line-height 1.72
- Номера стихов: `--muted2`, верхний индекс, sans-serif
- Греческие вставки (буквы): `--blue`, dotted underline
- Греческие слова (леммы/формы): `--terra`, dotted underline
- Max-width: 700px, центрирован
- Отступы: 18px 22px 60px

**Mode-widget**:
- Чип: компактный индикатор текущего состояния (α35% | λέγω 3)
- Попап: две вкладки — «Смешанный» и «Греческий»
- Вкладка «Смешанный»: слайдер интенсивности (0–100%) + тумблер (Выкл/Леммы/Формы) + кнопка словаря
- Вкладка «Греческий»: описание + чекбокс показа BSB под стихом
- Десктоп: поповер под чипом, 320px
- Мобильный: bottom-sheet

**Карточка слова**:
- Десктоп: инспектор-панель 364px справа (использовать `inspector.js`)
- Мобильный: bottom-sheet (использовать `bottom-sheet.js`)
- Контент карточки: лемма, транслитерация, русское значение, морфология, Strong's, частотность

### 3b — Словарь (`dictionary.js`)

- Заголовок: «Словарь» + счётчик `N слов`
- Поисковая строка: поиск по лемме/транслитерации
- Фильтры: строка статусов + строка частей речи (существующая логика, новый визуал)
- Список: карточки слов с рангом, леммой, транслитерацией, частотой, бейджем статуса
- Карточка: тап по строке → bottom-sheet с полной информацией и действиями (статус, показывать, интенсивность, формы)
- Чекбокс «Показывать в тексте» для каждого слова

### 3c — Настройки (`settings.js`)

**Выбор темы** — Идея 1 из `settings_ideas.md`:
- Сегментный переключатель: Система / Светлая / Тёмная
- Карточки-превью тем: сетка 3–4 в ряд, каждая с полосками цветов и названием
- Активная тема отмечена галочкой
- Один тап = применение
- На десктопе: две колонки (светлые / тёмные)
- На мобильном: секции друг под другом

**Контраст**: Soft / Sharp / Maximum (сегментный переключатель)

**Показывать**: тумблеры diacritics, Strong's, ruHint

**Прогресс букв**: существующая логика, новый визуал

### 3d — Онбординг + About + Прогресс

**Онбординг** (`onboarding.js`):
- 3 пресет-карточки с полосками-акцентами
- Шаг 1: выбор пресета + ввод букв
- Шаг 2: выбор стартовой главы

**About** (`about.js`):

**Прогресс** (`progress.js`):
