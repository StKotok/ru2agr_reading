# Редизайн виджета греческого слоя чтения

> Дизайн-спек · 2026-06-15 · статус: утверждён (v4)

## 1. Контекст

Текущий legacy-интерфейс верхней панели чтения: дропдаун «Режим N ▾»,
ползунок «Греческий: N%», кнопка «глаз». Дропдаун задаёт ложное ощущение
последовательности: будто пользователь выбирает один из четырёх взаимоисключающих
шагов.

**Проблема:** буквенная замена и словарная замена на самом деле независимы и
могут работать параллельно, а старый числовой selector скрывает эту модель.
Нет единого компактного индикатора текущего состояния греческого слоя.

**Решение:** заменить числовой selector и ползунок на единый компактный
виджет-чип с всплывающим окошком настроек.

## 2. Модель взаимодействия

Пользователь выбирает один из двух верхнеуровневых видов чтения:

1. **Смешанный текст** — русский текст остаётся основным, а греческий слой
   собирается из двух независимых настроек:
   - **Замена букв**: `intensity` 0–100%. Регулирует долю возможных буквенных
     замен (ru→gr). Работает сама по себе и одновременно со словарным слоем.
   - **Замена слов**: `wordLayer: 'off' | 'lemma' | 'form'`. `off` означает
     только буквенный слой без загрузки греческих слов и выравнивания. `lemma`
     включает словарные формы, `form` — реальные грамматические формы из
     оригинала.
2. **Греческий оригинал** — отдельный вид чтения: греческий текст становится
   основным, русский перевод показывается под стихом.

Нет продуктовой последовательности «1 → 2 → 3 → 4». Есть либо смешанный текст
с независимыми слоями `intensity` + `wordLayer`, либо отдельный греческий
оригинал.

### Настроенные слои и фактический рендер

Нужно различать два уровня:

- **UI state** — что выбрал пользователь: `readingMode`, `intensity`,
  `wordLayer`.
- **Compose mode** — внутренний adapter к текущему контракту `composeVerse`,
  который пока принимает числовой `mode`. Этот номер не пользовательский, не
  хранится в `settings` и не используется для UI-логики.

Если `wordLayer: 'lemma' | 'form'`, но активных слов в словаре нет
(`activeWordCount === 0`), текст фактически рендерится как только буквенный
слой, без загрузки греческой книги и без degraded-состояний словарного слоя.
При этом чип всё равно показывает намерение пользователя: `α35% · λέγω0` или
`α35% · λέγει0`.

В словаре per-word `forms` остаётся индивидуальной настройкой. Новые слова
могут не иметь явного `forms`; тогда используется глобальный `wordLayer`.
Если у слова `forms` задан явно, он переопределяет глобальное значение.

`buildWordEntries()` в `reading.js` при построении `wordEntries` использует:

```js
const globalForms = settings.wordLayer === 'form' ? 'form' : 'lemma';
forms: entry.forms || globalForms
```

Внутренний adapter к старому `composeVerse`:

| UI state | Внутренний `composeMode` | Загрузка Greek |
|---|---|---|
| `readingMode='mixed'`, `wordLayer='off'` | `LETTERS_ONLY` (`1`) | Не нужна |
| `readingMode='mixed'`, `wordLayer='lemma'`, активных слов 0 | `LETTERS_ONLY` (`1`) | Не нужна |
| `readingMode='mixed'`, `wordLayer='lemma'`, активных слов >0 | `WORD_LEMMA` (`2`) | Нужна |
| `readingMode='mixed'`, `wordLayer='form'`, активных слов 0 | `LETTERS_ONLY` (`1`) | Не нужна |
| `readingMode='mixed'`, `wordLayer='form'`, активных слов >0 | `WORD_FORM` (`3`) | Нужна |
| `readingMode='greek'` | `GREEK_ORIGINAL` (`4`) | Нужна |

### Состояния без греческого текста (degraded states)

Доступность греческой книги хранится не boolean-флагом, а состоянием
`grcStatus: 'idle' | 'loading' | 'available' | 'unavailable'`.
Это важно для смешанного текста без словарных замен: греческая книга может быть
ещё не загружена просто потому, что она не нужна. Вкладка «Греческий» должна
быть доступна в состояниях `idle`, `loading`, `available` и disabled только при
`unavailable`.

Когда `grcStatus === 'unavailable'` (офлайн-ошибка или книга без греческого
выравнивания):

- Если `wordLayer='off'` или `activeWordCount === 0`, греческие данные для
  смешанного view не нужны: работает буквенный слой, без degraded-тоста
  словарных замен.
- Если `wordLayer!='off'` и `activeWordCount > 0`, **словарная часть чипа
  заменяется на `—`** (нет данных для замены слов)
- **Вкладка «Греческий»** недоступна: показывается disabled-состояние таба
  с сообщением «Греческий текст недоступен — нет сети или для этой книги
  нет греческого оригинала»
- **Виджет показывает** буквенную часть (`α35%`) и, если словарный слой
  настроен, намерение с нулём (`λέγω0` / `λέγει0`) или `—` при активных словах

## 3. Виджет-чип (верхняя панель)

Компактный интерактивный индикатор в верхней панели. По клику открывает
всплывающее окошко.

### Состояния виджета

| Состояние | Виджет | Условие |
|---|---|---|
| Загрузка | `…` | Данные словаря/лексикона ещё не загружены |
| Только буквы | `α35%` | Слайдер >0%, `wordLayer='off'` |
| Буквы + леммы | `α35% · λέγω12` | Слайдер >0%, `wordLayer='lemma'`, N активных слов |
| Буквы + леммы, слов 0 | `α35% · λέγω0` | Слайдер >0%, `wordLayer='lemma'`, активных слов 0 |
| Буквы + формы | `α35% · λέγει12` | Слайдер >0%, `wordLayer='form'`, N активных слов |
| Буквы + формы, слов 0 | `α35% · λέγει0` | Слайдер >0%, `wordLayer='form'`, активных слов 0 |
| Буквы, слова недоступны | `α35% —` | Слайдер >0%, `wordLayer!='off'`, активных слов >0, `grcStatus='unavailable'` |
| Только леммы | `λέγω12` | Слайдер 0%, `wordLayer='lemma'`, N активных слов |
| Только леммы, слов 0 | `λέγω0` | Слайдер 0%, `wordLayer='lemma'`, активных слов 0 |
| Только формы | `λέγει12` | Слайдер 0%, `wordLayer='form'`, N активных слов |
| Только формы, слов 0 | `λέγει0` | Слайдер 0%, `wordLayer='form'`, активных слов 0 |
| Слова недоступны, букв нет | `—` | Слайдер 0%, `wordLayer!='off'`, активных слов >0, `grcStatus='unavailable'` |
| Без греческого слоя | `Рус` | Слайдер 0%, `wordLayer='off'` |
| Греческий оригинал | `Греч` | Активна вкладка «Греческий» |

### Стиль

- Шрифт: `var(--font-greek)` (Gentium Plus) для греческих символов, system-ui для мета-текста
- `α` — 18px, weight 500, цвет `var(--greek)` (#264e83)
- `λέγω` / `λέγει` — 18px, weight 500, цвет `var(--greek-word)` (#B07D4F)
- `35%` / `12` — 11px, weight 400, цвет `var(--muted)` (#8C8C8C)
- Разделитель `·` — цвет `var(--muted)` (контрастнее на фоне слов)
- Фон чипа: `var(--surface-card)`, border: `var(--border)`, border-radius: 14px
- Слово-индикатор: `λέγω` (лемма) / `λέγει` (форма) — глагол «говорить»

### Правила отображения

- Если `intensity === 0` — буквенная часть (`αN%`) скрывается
- Если `wordLayer === 'off'` — словарная часть (слово + счётчик) скрывается
- Если `wordLayer !== 'off'` — словарная часть показывается даже при
  `dictionaryWordCount === 0` (`λέγω0` / `λέγει0`)
- Если оба скрыты — показывается нейтральный индикатор «Рус»
- Если `grcStatus === 'unavailable'` и `dictionaryWordCount > 0` — словарная
  часть заменяется на `—`; если `intensity > 0`, чип показывает `αN% —`, если
  `intensity === 0` — только `—`. При `dictionaryWordCount === 0` показывается
  намерение (`λέγω0` / `λέγει0`), потому что греческие данные для рендера ещё
  не нужны
- **Счётчик слов** = количество записей в словаре, прошедших фильтр
  `buildWordEntries()`: статус `new|learning|known`, `showInText !== false`,
  с валидным `coreLexicon` или `frequencyList`. Это **глобальный** счётчик
  (все слова в словаре), без per-главу-тултипа
- **Состояние загрузки**: пока `dictionary`, `coreLexicon` и `frequencyList`
  не загружены, чип показывает `…` вместо числа

## 4. Всплывающее окошко

Открывается по клику на виджет-чип. Закрывается по клику снаружи или Escape.
Позиционируется как поповер рядом с чипом.

### Структура: две вкладки

```
┌──────────────────────────┐
│ [Смешанный] [Греческий]  │  ← табы
├──────────────────────────┤
│                          │
│  Замена букв      α35%  │  ← ползунок
│  [===========●======]   │
│  0% — чистый русский     │
│                          │
│  ─────────────────────── │  ← разделитель
│                          │
│  Замена слов             │
│  [ Выкл | Леммы | Формы ]│  ← тумблер
│  Выкл — только буквы…    │  ← подсказка
│  Леммы — как в словаре…  │  ← подсказка
│  Формы — как в тексте…   │
│                          │
│  📖 Словарь  выбрано 12→ │  ← кнопка
└──────────────────────────┘
```

### Вкладка «Смешанный»

- **Ползунок «Замена букв»**: range 0–100%, step 5, accent-color `--greek`,
  debounce 300ms перед `store.update()`. Подписи: «0% — чистый русский» /
  «100% — все буквы». Справа от заголовка — мини-чип `α35%` (без фона, без border).
- **Разделитель** (1px, `--border`)
- **Тумблер «Замена слов»**: три сегмента — «Выкл» / «Леммы» / «Формы».
  Активный — белый фон, `--text`, weight 500, тень.
  Неактивный — цвет `--muted`.
- **Подсказка** (11px, `--muted`):
  > **Выкл** — только буквы, без загрузки греческих слов
  > **Леммы** — как в словаре: λέγω  исходная форма, «говорить»
  > **Формы** — как в тексте: λέγει  с окончанием, «говорит»
- **Кнопка «📖 Словарь»** — во всю ширину, показывает количество выбранных слов.
  Ведёт на экран словаря (`#/dictionary`).

### Вкладка «Греческий»

- **Описание** (13px, `--text`): «Греческий текст Нового Завета как основной.
  Под каждым стихом — русский перевод мелким шрифтом.»
- **Чекбокс** «Показывать русский перевод под стихом» (по умолчанию включён)
- **Подсказка** (11px, `--muted`): «Нажмите на любое греческое слово — увидите
  перевод и разбор.»

## 5. Реализация

### Подход: единый компонент `mode-widget.js`

Один файл `src/ui/components/mode-widget.js`, экспортирующий
`createModeWidget({ store })`. Компонент инкапсулирует и чип, и попап.

Виджет вставляется в top-bar **снаружи** (как сейчас `intensity-slider`),
а не внутри `createTopBar`. `createTopBar` теряет modeBtn/modeList,
но сохраняет bookSelector и eyeBtn.

### Новая модель состояния

Нет пользователей → миграция IndexedDB не нужна. Просто расширяем DEFAULTS.

Новая модель хранит только пользовательские настройки: `readingMode`,
`intensity`, `wordLayer`. Поле `settings.mode` больше не является источником
правды и не должно сохраняться в IndexedDB. Если текущий `composeVerse` всё ещё
принимает числовой `mode`, `reading.js` вычисляет его локально как adapter.

```js
const COMPOSE_MODES = {
  LETTERS_ONLY: 1,
  WORD_LEMMA: 2,
  WORD_FORM: 3,
  GREEK_ORIGINAL: 4
};

function deriveComposeMode(s, activeWordCount) {
  if (s.readingMode === 'greek') return COMPOSE_MODES.GREEK_ORIGINAL;
  if (s.wordLayer === 'off') return COMPOSE_MODES.LETTERS_ONLY;
  if (activeWordCount === 0) return COMPOSE_MODES.LETTERS_ONLY;
  return s.wordLayer === 'form'
    ? COMPOSE_MODES.WORD_FORM
    : COMPOSE_MODES.WORD_LEMMA;
}

function shouldLoadGreek(s, activeWordCount) {
  return s.readingMode === 'greek' || (s.wordLayer !== 'off' && activeWordCount > 0);
}
```

`deriveComposeMode` вызывается в `reading.js` после построения `wordEntries` и
передаётся в `composeVerse`. UI-компоненты не читают и не записывают
`settings.mode`.

### Focus trap для попапа

В проекте нет готового focus-trap-компонента. `bottom-sheet.js` делает
упрощённый фокус первого элемента. Для `mode-widget` используем тот же подход:

- При открытии попапа: сохраняем `document.activeElement`, фокусим первый
  интерактивный элемент внутри попапа
- Tab на последнем элементе → фокус на первый; Shift+Tab на первом → фокус
  на последний (циклический trap)
- При закрытии: восстанавливаем фокус на чип

### Взаимодействие с plainView (кнопка «глаз»)

Кнопка «глаз» остаётся в top-bar и действует глобально:
- `plainView = true` → весь текст показывается как чистый русский,
  независимо от выбранной вкладки и настроек виджета
- При переключении вкладок (Смешанный↔Греческий) `plainView` **не сбрасывается**.
  Пользователь должен явно нажать «глаз» ещё раз, чтобы вернуть греческий слой
- Если `plainView = true`, чип виджета остаётся видимым и отражает
  текущие настройки (они не теряются, просто не применяются к отображению)

### Токены (существующие, без изменений)

```
--font-greek:    'Gentium Plus', serif  ← шрифт для греческих символов (светлая/тёмная — одинаково)
--surface:       #efeee9 / #1E1E1E  ← фон страницы (light / dark)
--surface-card:  #F2EDE4 / #2A2A2A  ← фон чипа, кнопок
--text:          #2B2B2B / #E0DCD0  ← основной текст
--muted:         #8C8C8C / #8C8C8C  ← мета-текст (%, счётчик)
--greek:         #264e83 / #7BA3CC  ← цвет буквы α
--greek-word:    #B07D4F / #D4A574  ← цвет слова λέγω/λέγει
--border:        #D9D3C7 / #3A3A3A  ← границы, разделители
```

Чип использует CSS-переменные, поэтому тёмная тема работает автоматически.
Для разделителя `·` в чипе используется `--muted` (а не `--greek-word`,
чтобы визуально отделять слово от разделителя).

### Доступность

- Чип: native `<button>`, `aria-label` с описанием состояния
- Попап: `role="dialog"`, `aria-label="Настройки чтения"`, focus trap
- Ползунок: `aria-label="Интенсивность замены букв"`
- Тумблер: `role="radiogroup"`, каждая опция — `role="radio"` с `aria-checked`
- Закрытие: Escape, клик снаружи

### Краевые случаи

- **Словарь пуст** (0 слов): если `wordLayer='off'`, словарная часть чипа
  скрыта; если `wordLayer='lemma'|'form'`, чип показывает `λέγω0` /
  `λέγει0`, а кнопка словаря показывает «выбрано 0 слов»
- **Слайдер на 0**: буквенная часть чипа скрыта
- **Слайдер на 0 + `wordLayer='off'`**: чип показывает нейтральный индикатор «Рус»
- **Слайдер на 0 + `wordLayer='lemma'|'form'` + слов 0**: чип показывает
  `λέγω0` / `λέγει0`
- **Слайдер на 0 + `wordLayer='lemma'|'form'` + активных слов >0 +
  `grcStatus='unavailable'`**: чип показывает `—`, потому что выбран только
  словарный слой, но он недоступен
- **Греческий текст не загружен** (офлайн / ошибка / нет выравнивания):
  если активных слов >0, словарная часть чипа скрывается принудительно
  (слово-индикатор → `—`), вкладка «Греческий» недоступна (disabled +
  сообщение). Если активных слов 0, греческий текст не грузится и
  degraded-состояние не показывается.
- **Греческий текст загрузился позже** (асинхронный `ensureGreekBookLoaded`):
  чип обновляется реактивно через store-подписку — словарная часть
  появляется, вкладка «Греческий» становится доступной
- **Словарь был не пуст, стал пуст** (пользователь удалил все слова):
  если `wordLayer='lemma'|'form'`, чип переходит из `α35% · λέγω12` →
  `α35% · λέγω0` (или `λέγει0`). Если `wordLayer='off'`, остаётся `α35%`.
  Переход мгновенный (без анимации для v1)
- **Мобильные (<900px)**: попап открывается как bottom sheet (использовать
  существующий `bottom-sheet.js`). Брейкпоинт 900px совпадает с остальным UI
  (поповеры карточек слов, боковая навигация)
- **Десктоп (≥900px)**: поповер рядом с чипом
- **Состояние загрузки**: пока `dictionary`, `coreLexicon` и `frequencyList`
  не загружены, чип показывает `…` вместо счётчика слов
- **Переключение вкладок при plainView**: `plainView = true` не сбрасывается
  при смене вкладки; пользователь явно отжимает «глаз» для возврата
  греческого слоя
- **Отсутствие alignment для конкретного стиха** при включённом словарном слое:
  `composeVerse` падает в letter-layer (только буквы) — виджет не меняет
  состояние, это per-стих поведение рендеринга, а не настроек

## 6. Что НЕ входит в этот дизайн

- Кнопка «глаз» (plain view) — остаётся без изменений
- Селектор книги — остаётся без изменений
- Экран словаря — без нового сценария из виджета; меняется только техническая
  настройка `forms`: появляется вариант «По виджету»
- Буквенный слой и алгоритм детерминированных буквенных замен не меняются

### Страница настроек после чистки

Управление греческим слоем полностью переезжает в mode-widget (top-bar).
На странице настроек (`#/settings`) остаются только:

- **Тема** — `auto | light | dark`
- **Показывать диакритику** (ударения, придыхания)
- **Показывать номера Стронга** (G3056)
- **Сброс** — кнопка сброса к заводским настройкам

Убираются: radio-кнопки режимов, слайдер интенсивности,
«Транслитерация», «Глосса / перевод», «Грамматика»,
«Новые слова за главу» вместе с «Сегодня не добавлять новое».
Количество новых слов за главу фиксируется на дефолте (3).

## 7. Финальные уточнения модели (июнь 2026)

После review зафиксированы следующие решения:

1. **Словарь всегда показывает леммы.** Экран словаря (`dictionary.js`) не
   использует per-word `forms` для отображения — строки/карточки всегда
   показывают лемму.
2. **Per-word `forms` управляет только заменами в тексте чтения.** Настройка
   «В тексте» в карточке слова меняет только поведение `buildWordEntries()`.
3. **Утверждённые значения `forms`:** отсутствие поля (по виджету), `'lemma'`,
   `'form'`. Значение `'all'` удалено из кода и тестов.
4. **`settings.mode` не хранится и не используется.** Внутренний
   `composeMode` — adapter, не пользовательская модель.
5. **`lastActiveTab` не сохраняется.** Активная вкладка попапа определяется
   из `readingMode`.
6. **Миграция IndexedDB не нужна** — пользователей нет.

## 8. Открытые вопросы

- Нужен ли анимированный переход между вкладками?
  **Решение:** нет для v1. CSS-класс `tab-transition` зарезервирован для
  будущей анимации.
- Показывать ли процент для «Греч» в чипе? (сейчас: просто `Греч`)
  **Решение:** нет. Чип показывает только `Греч` без цифр.
- Нужно ли запоминать последнюю активную вкладку между сессиями?
  **Решение (финальное):** нет. Активная вкладка попапа определяется из
  `readingMode` (`'greek'` → вкладка «Греческий», иначе «Смешанный»).
  `lastActiveTab` не сохраняется в настройках.
