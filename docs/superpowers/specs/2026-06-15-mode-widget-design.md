# Редизайн виджета переключателя режимов чтения

> Дизайн-спек · 2026-06-15 · статус: пересмотрен (2026-06-15, v2)

## 1. Контекст

Текущий интерфейс верхней панели чтения: дропдаун «Режим N ▾», ползунок «Греческий: N%»,
кнопка «глаз». Режимы 1–4 выбираются из выпадающего списка.

**Проблема:** режимы и интенсивность разнесены по разным элементам, нет единого
компактного индикатора текущего состояния.

**Решение:** заменить дропдаун режима и ползунок на единый компактный виджет-чип
с всплывающим окошком настроек.

## 2. Модель взаимодействия

Пользователь управляет греческим слоем по двум осям:

1. **Замена букв** — ползунок 0–100%. Регулирует, какая доля возможных
   буквенных замен (ru→gr) реально происходит. **Не влияет на словарные замены** —
   те управляются отдельно через словарь и тумблер.
2. **Замена слов** — тумблер «Леммы» / «Формы». Определяет, в каком виде
   подставляются греческие слова: словарная форма (лемма) или реальная
   грамматическая форма из оригинала.

### Приоритет глобального wordMode и per-word forms

В словаре каждая запись уже имеет поле `forms` (`'lemma'` | `'form'`),
задаваемое пользователем индивидуально для каждого слова.
Глобальный `wordMode` действует как **значение по умолчанию**: он влияет
только на слова, у которых `forms` не задан явно. Если у слова
`forms: 'lemma'`, а глобально `wordMode: 'form'` — побеждает per-word
настройка (`'lemma'`).

`buildWordEntries()` в `reading.js` при построении `wordEntries` для
`composeVerse` использует `entry.forms || settings.wordMode`.

Старые 4 режима отображаются в новую модель так:

| Старый режим | Новое состояние | Без греческого текста |
|---|---|---|
| 1. Буквы + подсказки | Слайдер >0%, тумблер неважен (нет слов в словаре) | Работает всегда (letter-layer) |
| 2. Слова из словаря (леммы) | Слайдер любой, wordMode='lemma', слова в словаре | Падает до режима 1 (только буквы) |
| 3. Формы оригинала | Слайдер любой, wordMode='form', слова в словаре | Падает до режима 1 (только буквы) |
| 4. Почти оригинал | Вкладка «Греческий» — отдельный режим | Показывается русский текст как fallback |

Третья ось — **вкладка «Смешанный» / «Греческий»**:
- «Смешанный» — русский текст с греческим слоем (режимы 1–3)
- «Греческий» — греческий текст как основной, русский перевод под стихом (режим 4)

### Состояния без греческого текста (degraded states)

Когда `grcBookData === null` (греческий текст не загружен — офлайн, ошибка
сети, или книга без греческого выравнивания):

- **Словарная часть чипа скрывается** (нет данных для замены слов)
- **Вкладка «Греческий»** недоступна: показывается disabled-состояние таба
  с сообщением «Греческий текст недоступен — нет сети или для этой книги
  нет греческого оригинала»
- **Виджет показывает** только буквенную часть (`α35%`), либо,
  если и слайдер на 0 — нейтральный индикатор «Рус»

## 3. Виджет-чип (верхняя панель)

Компактный интерактивный индикатор в верхней панели. По клику открывает
всплывающее окошко.

### Состояния виджета

| Состояние | Виджет | Условие |
|---|---|---|
| Только буквы | `α35%` | Слайдер >0%, нет слов в словаре |
| Буквы + леммы | `α35% · λέγω12` | Слайдер >0%, тумблер «Леммы», N слов |
| Буквы + формы | `α35% · λέγει12` | Слайдер >0%, тумблер «Формы», N слов |
| Только леммы | `λέγω12` | Слайдер 0%, тумблер «Леммы», N слов |
| Только формы | `λέγει12` | Слайдер 0%, тумблер «Формы», N слов |
| Греческий оригинал | `Греч` | Активна вкладка «Греческий» |

### Стиль

- Шрифт: `var(--font-greek)` (Gentium Plus) для греческих символов, system-ui для мета-текста
- `α` — 18px, weight 500, цвет `var(--greek)` (#264e83)
- `λέγω` / `λέγει` — 18px, weight 500, цвет `var(--greek-word)` (#B07D4F)
- `35%` / `12` — 11px, weight 400, цвет `var(--muted)` (#8C8C8C)
- Разделитель `·` — цвет `var(--muted)` (контрастнее на фоне слов)
- Фон чипа: `var(--surface-card)`, border: `var(--border)`, border-radius: 14px
- Слово-индикатор: `λέγω` (лемма) / `λέγει` (форма) — глагол «говорить»

### Правила отображения

- Если `intensity === 0` — буквенная часть (`αN%`) скрывается
- Если `dictionaryWordCount === 0` — словарная часть (слово + счётчик) скрывается
- Если оба скрыты — показывается нейтральный индикатор «Рус»
- Если `grcBookData === null` — словарная часть скрывается принудительно
  (слово-индикатор заменяется на `—`)
- **Счётчик слов** = количество записей в словаре, прошедших фильтр
  `buildWordEntries()`: статус `new|learning|known`, `showInText !== false`,
  с валидным `coreLexicon` или `frequencyList`. Это **глобальный** счётчик
  (все слова в словаре), без per-главу-тултипа
- **Состояние загрузки**: пока `dictionary`, `coreLexicon` и `frequencyList`
  не загружены, чип показывает `…` вместо числа

## 4. Всплывающее окошко

Открывается по клику на виджет-чип. Закрывается по клику снаружи или Escape.
Позиционируется как поповер рядом с чипом.

### Структура: две вкладки

```
┌──────────────────────────┐
│ [Смешанный] [Греческий]  │  ← табы
├──────────────────────────┤
│                          │
│  Замена букв      α35%  │  ← ползунок
│  [===========●======]   │
│  0% — чистый русский     │
│                          │
│  ─────────────────────── │  ← разделитель
│                          │
│  Замена слов             │
│  [  Леммы  |  Формы  ]  │  ← тумблер
│  Леммы — как в словаре…  │  ← подсказка
│  Формы — как в тексте…   │
│                          │
│  📖 Словарь  выбрано 12→ │  ← кнопка
└──────────────────────────┘
```

### Вкладка «Смешанный»

- **Ползунок «Замена букв»**: range 0–100%, step 5, accent-color `--greek`,
  debounce 300ms перед `store.update()`. Подписи: «0% — чистый русский» /
  «100% — все буквы». Справа от заголовка — мини-чип `α35%` (без фона, без border).
- **Разделитель** (1px, `--border`)
- **Тумблер «Замена слов»**: два сегмента — «Леммы» / «Формы».
  Активный — белый фон, `--text`, weight 500, тень.
  Неактивный — цвет `--muted`.
- **Подсказка** (11px, `--muted`):
  > **Леммы** — как в словаре: λέγω  исходная форма, «говорить»
  > **Формы** — как в тексте: λέγει  с окончанием, «говорит»
- **Кнопка «📖 Словарь»** — во всю ширину, показывает количество выбранных слов.
  Ведёт на экран словаря (`#/dictionary`).

### Вкладка «Греческий»

- **Описание** (13px, `--text`): «Греческий текст Нового Завета как основной.
  Под каждым стихом — русский перевод мелким шрифтом.»
- **Чекбокс** «Показывать русский перевод под стихом» (по умолчанию включён)
- **Подсказка** (11px, `--muted`): «Нажмите на любое греческое слово — увидите
  перевод и разбор.»

## 5. Реализация

### Подход: единый компонент `mode-widget.js`

Один файл `src/ui/components/mode-widget.js`, экспортирующий
`createModeWidget({ store })`. Компонент инкапсулирует и чип, и попап.

Виджет вставляется в top-bar **снаружи** (как сейчас `intensity-slider`),
а не внутри `createTopBar`. `createTopBar` теряет modeBtn/modeList,
но сохраняет bookSelector и eyeBtn.

### Миграция состояния (критично)

Старые пользователи имеют в IndexedDB: `{ mode: 1|2|3|4, intensity: 35, ... }`.
Новая модель: `wordMode`, `readingMode`, плюс сохранение `mode` как
derived-поля для совместимости с `composeVerse()`.

**Функция миграции** `migrateSettings(old)` в `src/state/settings.js`:

```js
function migrateSettings(loaded) {
  if (loaded._schemaVersion === 1) return loaded; // уже мигрировано

  const migrated = { ...loaded, _schemaVersion: 1 };

  // Вычисляем новые поля из старого mode
  if (!migrated.wordMode) {
    migrated.wordMode = (loaded.mode === 3) ? 'form' : 'lemma';
  }
  if (!migrated.readingMode) {
    migrated.readingMode = (loaded.mode === 4) ? 'greek' : 'mixed';
  }
  if (!migrated.lastActiveTab) {
    migrated.lastActiveTab = 'mixed';
  }

  // mode остаётся как derived (вычисляется ниже)
  migrated.mode = deriveMode(migrated);
  return migrated;
}

function deriveMode(s) {
  if (s.readingMode === 'greek') return 4;
  if (s.intensity > 0 && s.wordMode === 'lemma') return 2;
  if (s.wordMode === 'form') return 3;
  return 1;
}
```

`deriveMode` вызывается при каждом изменении `intensity`, `wordMode` или
`readingMode` — результат записывается в `settings.mode` для обратной
совместимости со всем кодом (`composeVerse`, `ensureGreekBookLoaded`,
условия `mode >= 2`, экран настроек).

### Focus trap для попапа

В проекте нет готового focus-trap-компонента. `bottom-sheet.js` делает
упрощённый фокус первого элемента. Для `mode-widget` используем тот же подход:

- При открытии попапа: сохраняем `document.activeElement`, фокусим первый
  интерактивный элемент внутри попапа
- Tab на последнем элементе → фокус на первый; Shift+Tab на первом → фокус
  на последний (циклический trap)
- При закрытии: восстанавливаем фокус на чип

### Взаимодействие с plainView (кнопка «глаз»)

Кнопка «глаз» остаётся в top-bar и действует глобально:
- `plainView = true` → весь текст показывается как чистый русский,
  независимо от выбранной вкладки и настроек виджета
- При переключении вкладок (Смешанный↔Греческий) `plainView` **не сбрасывается**.
  Пользователь должен явно нажать «глаз» ещё раз, чтобы вернуть греческий слой
- Если `plainView = true`, чип виджета остаётся видимым и отражает
  текущие настройки (они не теряются, просто не применяются к отображению)

### Токены (существующие, без изменений)

```
--surface:       #efeee9 / #1E1E1E  ← фон страницы (light / dark)
--surface-card:  #F2EDE4 / #2A2A2A  ← фон чипа, кнопок
--text:          #2B2B2B / #E0DCD0  ← основной текст
--muted:         #8C8C8C / #8C8C8C  ← мета-текст (%, счётчик)
--greek:         #264e83 / #7BA3CC  ← цвет буквы α
--greek-word:    #B07D4F / #D4A574  ← цвет слова λέγω/λέγει
--border:        #D9D3C7 / #3A3A3A  ← границы, разделители
```

Чип использует CSS-переменные, поэтому тёмная тема работает автоматически.
Для разделителя `·` в чипе используется `--muted` (а не `--greek-word`,
чтобы визуально отделять слово от разделителя).

### Доступность

- Чип: `role="button"`, `tabindex="0"`, `aria-label` с описанием состояния
- Попап: `role="dialog"`, `aria-label="Настройки чтения"`, focus trap
- Ползунок: `aria-label="Интенсивность замены букв"`
- Тумблер: `role="radiogroup"`, каждая опция — `role="radio"` с `aria-checked`
- Закрытие: Escape, клик снаружи

### Краевые случаи

- **Словарь пуст** (0 слов): словарная часть чипа скрыта, кнопка словаря
  показывает «выбрано 0 слов»
- **Слайдер на 0**: буквенная часть чипа скрыта
- **Слайдер на 0 + словарь пуст**: чип показывает нейтральный индикатор «Рус»
- **Греческий текст не загружен** (офлайн / ошибка / нет выравнивания):
  словарная часть чипа скрывается принудительно (слово-индикатор → `—`),
  вкладка «Греческий» недоступна (disabled + сообщение), виджет показывает
  только буквенную часть или «Рус»
- **Греческий текст загрузился позже** (асинхронный `ensureGreekBookLoaded`):
  чип обновляется реактивно через store-подписку — словарная часть
  появляется, вкладка «Греческий» становится доступной
- **Словарь был не пуст, стал пуст** (пользователь удалил все слова):
  чип переходит из `α35% · λέγω12` → `α35%`. Переход мгновенный
  (без анимации для v1)
- **Мобильные (<900px)**: попап открывается как bottom sheet (использовать
  существующий `bottom-sheet.js`). Брейкпоинт 900px совпадает с остальным UI
  (поповеры карточек слов, боковая навигация)
- **Десктоп (≥900px)**: поповер рядом с чипом
- **Состояние загрузки**: пока `dictionary`, `coreLexicon` и `frequencyList`
  не загружены, чип показывает `…` вместо счётчика слов
- **Переключение вкладок при plainView**: `plainView = true` не сбрасывается
  при смене вкладки; пользователь явно отжимает «глаз» для возврата
  греческого слоя
- **Отсутствие alignment для конкретного стиха** (режимы 2–3): composeVerse
  падает в letter-layer (только буквы) — виджет не меняет состояние, это
  per-стих поведение рендеринга, а не настроек

## 6. Что НЕ входит в этот дизайн

- Кнопка «глаз» (plain view) — остаётся без изменений
- Селектор книги — остаётся без изменений
- Экран словаря — остаётся без изменений, виджет только ведёт на него
- Сами режимы рендеринга (compose.js, letter-layer.js) — логика замен не меняется

### Страница настроек после чистки

Управление режимом чтения полностью переезжает в mode-widget (top-bar).
На странице настроек (`#/settings`) остаются только:

- **Тема** — `auto | light | dark`
- **Показывать диакритику** (ударения, придыхания)
- **Показывать номера Стронга** (G3056)
- **Сброс** — кнопка сброса к заводским настройкам

Убираются: radio-кнопки режимов, слайдер интенсивности,
«Транслитерация», «Глосса / перевод», «Грамматика».

## 7. Открытые вопросы

- Нужен ли анимированный переход между вкладками?
  **Решение:** нет для v1. CSS-класс `tab-transition` зарезервирован для
  будущей анимации.
- Показывать ли процент для «Греч» в чипе? (сейчас: просто `Греч`)
  **Решение:** нет. Чип показывает только `Греч` без цифр.
- Нужно ли запоминать последнюю активную вкладку между сессиями?
  **Решение:** да, сохранять в `settings.lastActiveTab: 'mixed' | 'greek'`
  (по умолчанию `'mixed'`).
