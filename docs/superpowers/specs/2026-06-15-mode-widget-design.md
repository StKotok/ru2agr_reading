# Редизайн виджета переключателя режимов чтения

> Дизайн-спек · 2026-06-15 · статус: утверждён

## 1. Контекст

Текущий интерфейс верхней панели чтения: дропдаун «Режим N ▾», ползунок «Греческий: N%»,
кнопка «глаз». Режимы 1–4 выбираются из выпадающего списка.

**Проблема:** режимы и интенсивность разнесены по разным элементам, нет единого
компактного индикатора текущего состояния.

**Решение:** заменить дропдаун режима и ползунок на единый компактный виджет-чип
с всплывающим окошком настроек.

## 2. Модель взаимодействия

Пользователь управляет греческим слоем по двум осям:

1. **Замена букв** — ползунок 0–100%. Регулирует, какая доля возможных
   буквенных замен (ru→gr) реально происходит.
2. **Замена слов** — тумблер «Леммы» / «Формы». Определяет, в каком виде
   подставляются греческие слова: словарная форма (лемма) или реальная
   грамматическая форма из оригинала.

Старые 4 режима отображаются в новую модель так:

| Старый режим | Новое состояние |
|---|---|
| 1. Буквы + подсказки | Слайдер >0%, тумблер неважен (нет слов в словаре) |
| 2. Слова из словаря (леммы) | Слайдер любой, тумблер «Леммы», слова в словаре |
| 3. Формы оригинала | Слайдер любой, тумблер «Формы», слова в словаре |
| 4. Почти оригинал | Вкладка «Греческий» — отдельный режим |

Третья ось — **вкладка «Смешанный» / «Греческий»**:
- «Смешанный» — русский текст с греческим слоем (режимы 1–3)
- «Греческий» — греческий текст как основной, русский перевод под стихом (режим 4)

## 3. Виджет-чип (верхняя панель)

Компактный интерактивный индикатор в верхней панели. По клику открывает
всплывающее окошко.

### Состояния виджета

| Состояние | Виджет | Условие |
|---|---|---|
| Только буквы | `α35%` | Слайдер >0%, нет слов в словаре |
| Буквы + леммы | `α35% · λέγω12` | Слайдер >0%, тумблер «Леммы», N слов |
| Буквы + формы | `α35% · λέγει12` | Слайдер >0%, тумблер «Формы», N слов |
| Только леммы | `λέγω12` | Слайдер 0%, тумблер «Леммы», N слов |
| Только формы | `λέγει12` | Слайдер 0%, тумблер «Формы», N слов |
| Греческий оригинал | `Греч` | Активна вкладка «Греческий» |

### Стиль

- Шрифт: Gentium Plus для греческих символов, system-ui для мета-текста
- `α` — 18px, weight 500, цвет `--greek` (#264e83)
- `λέγω` / `λέγει` — 18px, weight 500, цвет `--greek-word` (#B07D4F)
- `35%` / `12` — 11px, weight 400, цвет `--muted` (#8C8C8C)
- Разделитель `·` — цвет `--greek-word`
- Фон чипа: `--surface-card`, border: `--border`, border-radius: 14px
- Слово-индикатор: `λέγω` (лемма) / `λέγει` (форма) — глагол «говорить»

### Правила отображения

- Если `intensity === 0` — буквенная часть (`αN%`) скрывается
- Если `dictionaryWordCount === 0` — словарная часть (слово + счётчик) скрывается
- Если оба скрыты — показывается нейтральный индикатор или виджет скрывается
- Счётчик слов = количество слов в словаре со статусом new/learning/known и showInText !== false

## 4. Всплывающее окошко

Открывается по клику на виджет-чип. Закрывается по клику снаружи или Escape.
Позиционируется как поповер рядом с чипом.

### Структура: две вкладки

```
┌──────────────────────────┐
│ [Смешанный] [Греческий]  │  ← табы
├──────────────────────────┤
│                          │
│  Замена букв      α35%  │  ← ползунок
│  [===========●======]   │
│  0% — чистый русский     │
│                          │
│  ─────────────────────── │  ← разделитель
│                          │
│  Замена слов             │
│  [  Леммы  |  Формы  ]  │  ← тумблер
│  Леммы — как в словаре…  │  ← подсказка
│  Формы — как в тексте…   │
│                          │
│  📖 Словарь  выбрано 12→ │  ← кнопка
└──────────────────────────┘
```

### Вкладка «Смешанный»

- **Ползунок «Замена букв»**: range 0–100%, step 5, accent-color `--greek`.
  Подписи: «0% — чистый русский» / «100% — все буквы».
  Справа от заголовка — мини-чип `α35%` (без фона, без border).
- **Разделитель** (1px, `--border`)
- **Тумблер «Замена слов»**: два сегмента — «Леммы» / «Формы».
  Активный — белый фон, `--text`, weight 500, тень.
  Неактивный — цвет `--muted`.
- **Подсказка** (11px, `--muted`):
  > **Леммы** — как в словаре: λέγω  исходная форма, «говорить»
  > **Формы** — как в тексте: λέγει  с окончанием, «говорит»
- **Кнопка «📖 Словарь»** — во всю ширину, показывает количество выбранных слов.
  Ведёт на экран словаря (`#/dictionary`).

### Вкладка «Греческий»

- **Описание** (13px, `--text`): «Греческий текст Нового Завета как основной.
  Под каждым стихом — русский перевод мелким шрифтом.»
- **Чекбокс** «Показывать русский перевод под стихом» (по умолчанию включён)
- **Подсказка** (11px, `--muted`): «Нажмите на любое греческое слово — увидите
  перевод и разбор.»

## 5. Реализация

### Подход: единый компонент `mode-widget.js`

Один файл `src/ui/components/mode-widget.js`, экспортирующий
`createModeWidget({ store })`. Компонент инкапсулирует и чип, и попап.

### Изменения в коде

| Файл | Изменение |
|---|---|
| `src/ui/components/mode-widget.js` | **Новый.** Чип + попап с табами, ползунком, тумблером, кнопкой словаря |
| `src/ui/components/top-bar.js` | Убрать modeBtn, modeList, slider. Добавить `createModeWidget`. Убрать импорт `MODES` (переедет в mode-widget) |
| `src/ui/screens/reading.js` | Убрать создание IntensitySlider (логика в mode-widget). Слайдер больше не отдельный компонент в top-bar |
| `src/ui/components/intensity-slider.js` | Удалить или оставить как внутреннюю утилиту |
| `src/state/settings.js` | `loadSettings` должен предоставлять `wordMode: 'lemma' \| 'form'` и `readingMode: 'mixed' \| 'greek'` |

### Токены (существующие, без изменений)

```
--surface:       #efeee9   ← фон страницы
--surface-card:  #F2EDE4   ← фон чипа, кнопок
--text:          #2B2B2B   ← основной текст
--muted:         #8C8C8C   ← мета-текст (%, счётчик)
--greek:         #264e83   ← цвет буквы α
--greek-word:    #B07D4F   ← цвет слова λέγω/λέγει
--border:        #D9D3C7   ← границы, разделители
```

### Доступность

- Чип: `role="button"`, `tabindex="0"`, `aria-label` с описанием состояния
- Попап: `role="dialog"`, `aria-label="Настройки чтения"`, focus trap
- Ползунок: `aria-label="Интенсивность замены букв"`
- Тумблер: `role="radiogroup"`, каждая опция — `role="radio"` с `aria-checked`
- Закрытие: Escape, клик снаружи

### Краевые случаи

- **Словарь пуст** (0 слов): словарная часть чипа скрыта, кнопка словаря
  показывает «выбрано 0 слов»
- **Слайдер на 0**: буквенная часть чипа скрыта
- **Греческий текст не загружен** (офлайн): вкладка «Греческий» недоступна,
  показывается сообщение
- **Мобильные (<600px)**: попау открывается как bottom sheet (использовать
  существующий `bottom-sheet.js`)
- **Десктоп (≥600px)**: поповер рядом с чипом

## 6. Что НЕ входит в этот дизайн

- Кнопка «глаз» (plain view) — остаётся без изменений
- Селектор книги — остаётся без изменений
- Экран словаря — остаётся без изменений, виджет только ведёт на него
- Сами режимы рендеринга (compose.js, letter-layer.js) — логика замен не меняется
