# Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Full visual redesign of the application matching the design prototype in `docs/ru2gr_design-example/project/`, in 3 layers: tokens+CSS, shell+nav, screens.

**Architecture:** Replace CSS custom properties with 12-theme system from prototype. Rebuild shell as flex container with side nav (desktop) / bottom nav (mobile). Restyle all screens — reading, dictionary, settings, onboarding, about, progress — while preserving all engine/data/state logic.

**Tech Stack:** Vanilla JS, CSS custom properties, Vite, Gentium Plus + Source Sans 3 fonts.

## Global Constraints

- Vanilla JS only — no React/Vue/Svelte
- All visible user text in Russian
- UI screens follow `mount(container, ctx)` / `unmount()` contract
- Engine (`src/engine/**`) unchanged
- Data loaders (`src/data/**`) unchanged
- State management (`src/state/**`) logic unchanged
- IndexedDB schema unchanged
- PWA untouched
- 220 tests must stay green
- `npm run build` must pass after each layer

- [ ] **Step 1: Write the new createNav function**

```js
import { iconRead, iconDict, iconProgress, iconGear } from './icons.js';

export function createNav(store) {
  const nav = document.createElement('nav');
  nav.className = 'app-nav';

  const tabs = [
    { id: 'reading',    icon: iconRead,     label: 'Чтение' },
    { id: 'dictionary', icon: iconDict,     label: 'Словарь' },
    { id: 'progress',   icon: iconProgress, label: 'Прогресс' },
    { id: 'settings',   icon: iconGear,     label: 'Ещё' },
  ];

  tabs.forEach(({ id, icon, label }) => {
    const btn = document.createElement('button');
    btn.className = 'nav-tab';
    btn.setAttribute('aria-label', label);
    btn.innerHTML = `${icon()}<span class="nav-tab-label">${label}</span>`;
    btn.addEventListener('click', () => {
      location.hash = id === 'reading' ? '#/read/john' : `#/${id}`;
    });
    nav.appendChild(btn);
  });

  // Highlight active tab
  function updateActive() {
    const screen = store.get().screen || 'reading';
    nav.querySelectorAll('.nav-tab').forEach((btn, i) => {
      btn.classList.toggle('active', tabs[i].id === screen);
    });
  }

  store.subscribe(['screen'], updateActive);
  updateActive();

  return nav;
}
```

```js
import { iconEye } from './icons.js';

export function createTopBar({ store, onEyeToggle }) {
  const bar = document.createElement('header');
  bar.className = 'top-header';

  // Book + chapter label
  const bookLabel = document.createElement('button');
  bookLabel.className = 'top-header-book';
  bookLabel.innerHTML = `<span class="top-header-book-name">...</span>`;
  bar.appendChild(bookLabel);

  // Eye toggle (simple view)
  const eyeBtn = document.createElement('button');
  eyeBtn.className = 'top-header-eye';
  eyeBtn.setAttribute('aria-label', 'Простой вид');
  eyeBtn.innerHTML = iconEye(false, false);
  eyeBtn.addEventListener('click', () => {
    const pressed = eyeBtn.classList.toggle('active');
    onEyeToggle(pressed);
  });
  bar.appendChild(eyeBtn);

  // Update book label when store changes
  store.subscribe(['book'], () => {
    const state = store.get();
    const bookId = state.book || 'john';
    const books = state.books || [];
    const book = books.find(b => b.id === bookId);
    if (book) {
      bookLabel.querySelector('.top-header-book-name').textContent = book.short + ',';
    }
  });

  return { bar, bookLabel };
}
```
