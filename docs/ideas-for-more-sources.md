
I. Текущая модель данных

Карточка слова (word-card.js) рендерит 8 настраиваемых секций. Данные собираются в reading.js:collectWordData() из:
- HTML data-атрибутов на <span> (surface, lemma, morph, strongs, original)
- core.json (5 468 лемм, загружается в coreByIdCache)
- frequency.json (частотность через freqByKeyCache)
- Пользовательского словаря (IndexedDB)

Прямо сейчас работают: грамматика, частотность, лемма, перевод в стихе, статус изучения,
**определение, происхождение, транскрипция произношения** (исправлено `7fed4560`).

II. Что найдено во внешних источниках

🏆 Главная находка: UBS SDGNT (открытый Louw-Nida)

https://github.com/ubsicap/ubs-open-license

UBS опубликовали Semantic Dictionary of the Greek New Testament под CC BY-SA 4.0. Это:
- Полноценный преемник Louw-Nida с открытой лицензией
- Определения по каждому значению слова
- Глоссы (английские)
- Все места НЗ для каждого значения
- Классификация по семантическим доменам (93 домена)
- Формат: XML и JSON — machine-readable

Раньше проект исключил Louw-Nida (@ln) из-за лицензии UBS. Теперь UBS сами открыли данные — это самое ценное возможное дополнение.

📚 Этимология: Abbott-Smith Lexicon

https://github.com/biblicalhumanities/Abbott-Smith

- 5 726 статей, Public Domain / CC0
- Структурированный TEI XML
- Содержит этимологию для большинства слов
- Можно использовать для углубления туда, где Strong's derivation ограничивается «of Hebrew origin»
