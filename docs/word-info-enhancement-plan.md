### Ключевые файлы, которые будут меняться

| Файл | Роль |
|---|---|
| `scripts/build-lexicon.mjs` | Сборка core.json — добавление полей |
| `assets/data/lexicon/core.json` | Выход сборки — потребляет рантайм |
| `src/ui/screens/reading.js` | `collectWordData()` — сбор данных для карточки |
| `src/ui/components/word-card.js` | `renderWordCard()` — рендер карточки |
| `src/state/card-settings.js` | `CARD_SECTIONS` — регистрация новых секций |
| `src/engine/morphology.js` | Форматирование морфологии (может расширяться) |

### Общий контракт данных

Все новые данные проходят путь:
```
source-data → build-lexicon.mjs → core.json → lexicon-loader.js → reading.js:collectWordData → word-card.js
```

Каждая новая секция карточки:
1. Регистрируется в `CARD_SECTIONS` (card-settings.js)
2. Добавляется в `sectionEls` внутри `renderWordCard()` (word-card.js)
3. Получает `<div>` с классом и меткой
4. Управляется галочкой в шестерёнке (порядок + видимость)

## Зависимости между P-уровнями

```
P1 (автономен) ──┐
                  ├──▶ можно делать параллельно
P2 (автономен) ──┘

P3 (SDGNT) — зависит от доступности репозитория ubsicap, автономен относительно P1/P2

P4 (аудио + этимология) — автономен, можно начинать исследование TTS в любое время
```

P1 и P2 можно делать в одном PR как «быстрые побеги». P3 — отдельный PR (новый источник данных). P4 — либо отдельный PR, либо два (аудио + этимология раздельно).
