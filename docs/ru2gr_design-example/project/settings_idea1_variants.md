# Идея 1: Системный авто-режим + парные карточки тем — 2 варианта исполнения

**Базовый концепт (из `settings_ideas.md`):** сегментный переключатель режима
`[🌓 Система] [☀️ Светлая] [🌙 Тёмная]` + два ряда карточек-превью тем — светлые и тёмные.

Ниже — два альтернативных варианта реализации этого же концепта, с разными
компромиссами по компактности, информативности и визуальной подаче.

---

## Вариант A: Карусель с живым превью текста

### Отличие от базовой идеи
Вместо статичных цветовых квадратиков — **горизонтальная карусель крупных карточек**.
Каждая карточка показывает **реальный фрагмент текста** (Ин 1:1–3, греческий + русский),
отрендеренный в цветах выбранной темы. Пользователь листает карусель влево-вправо
и **сразу видит, как будет выглядеть чтение**.

Сверху — переключатель «Светлые / Тёмные» (или две параллельные карусели на
десктопе). Текущая выбранная тема отмечена галочкой и обведена акцентным цветом.

### Почему это работает лучше базовой идеи
- **Живой текст** > цветовой квадратик: пользователь оценивает не цвета, а **читаемость**
- **Одна карточка в фокусе** снижает когнитивную нагрузку (эффект «выбора из 3», а не из 12)
- **Свайп** — естественный жест на мобильном; на десктопе — стрелки или скролл
- Карусель создаёт **ощущение исследования**: «полистаю, посмотрю что подходит»

### Поведение
- **Свайп влево/вправо** листает карточки в пределах одной группы (светлые/тёмные)
- **Тап по карточке** — мгновенное применение темы
- **Стрелки ◀ ▶** — альтернатива свайпу (десктоп, accessibility)
- **Точки-индикаторы** показывают позицию в карусели и общее количество
- При выборе темы — микро-анимация: карточка чуть увеличивается (scale 1.02)
  и появляется галочка, затем фон страницы плавно (300ms ease-out) переходит
  в новую тему
- На **десктопе** (≥768px) — две карусели рядом: светлые слева, тёмные справа

### Состояния карточки
```
Не выбрана:           Выбрана:              В фокусе (клавиатура):
┌──────────────┐    ┌──────────────┐       ┌──────────────┐
│              │    │ ┌──────────┐ │       ╔══════════════╗
│  текст ...   │    │ │ текст ... │ │       ║  текст ...   ║
│              │    │ └──────────┘ │       ║              ║
│  Сепия       │    │  Сепия  ✓   │       ║  Сепия       ║
└──────────────┘    └──────────────┘       ╚══════════════╝
   opacity: 0.7       scale: 1.02           outline: 2px
                      border: accent        border-radius: 12px
```

### Плюсы
- Живой текст — никаких догадок, видно реальную читаемость
- Карусель = естественный мобильный паттерн
- Одна карточка в фокусе = нет «паралича выбора»
- Эффектно выглядит, создаёт «опыт выбора», а не скучную настройку
- Греческий текст в превью — смысловая нагрузка, не lorem ipsum

### Минусы
- Требует больше места по вертикали (~300px на мобильном)
- Сложнее в реализации: нужен рендер текста в 12 цветовых схемах
- Чтобы увидеть все 9 светлых тем, нужно пролистать 8 раз — медленнее,
  чем сетка
- На очень маленьких экранах (≤375px) карточка с текстом может быть тесновата
- Нужно аккуратно подобрать размер текста в превью, чтобы он был читаем
  во всех темах

### Accessibility-заметки
- Стрелки ◀ ▶ — настоящие `<button>` с `aria-label="Предыдущая тема"` /
  `"Следующая тема"`
- Индикатор позиции: `aria-live="polite"` объявляет «Тема 3 из 9: Сепия»
- Карточка-превью: `role="option"`, `aria-selected="true/false"`
- Обёртка карусели: `role="listbox"`, `aria-label="Выбор светлой темы"`
- При фокусе на карточке — клавиши ← → листают карусель, Enter/Space выбирает

## Вариант B: Компактные слоты с поповером-галереей

### Отличие от базовой идеи
Вместо всегда видимых рядов карточек — **два компактных слота** (как в Идее 5,
но проще). Каждый слот показывает **название текущей темы + цветовой свотч**.
При тапе на слот — открывается **поповер (popover) с сеткой карточек-превью**.

На десктопе поповер открывается рядом со слотом. На мобильном — bottom sheet
(шторка снизу).

### Почему это работает лучше базовой идеи
- **Экономия места**: в свёрнутом виде — 2 строки по ~40px. Подходит для экрана
  настроек, где тема — лишь одна из многих опций
- **Прогрессивное раскрытие**: пользователь видит текущий выбор, детали — по запросу
- **Привычный паттерн**: поповер/шторка = стандартный iOS/Android паттерн выбора
  из коллекции
- **Слоты можно разместить где угодно** — в шапке, в боковой панели, в отдельной
  секции настроек — не требуя пол-экрана под сетку

### Поведение
- **Тап по слоту** → открывается поповер/шторка с сеткой тем этой группы
- **Тап по карточке** в поповере → тема применена, поповер закрывается
  (мгновенно, с анимацией фона 250ms)
- **Тап вне поповера** или **Esc** → закрыть без изменений
- **Поповер позиционируется** якорем к слоту (десктоп); шторка — снизу (мобильный)
- При **режиме «Система»** — оба слота активны
- При **режиме «Светлая»** — тёмный слот становится неактивным (opacity 0.4,
  не кликабелен, подпись «Не используется»)
- Долгое нажатие на слот — быстрый превью: фон страницы временно переключается
  в тему под пальцем (как 3D Touch / Haptic Touch), отпустил — вернулся обратно

### Состояния слота
```

                         стрелка сдвигается      стрелка повёрнута
                         вправо (micro-spring)   вверх (popover open)
```

### Плюсы
- **Очень компактно** в свёрнутом виде — 2 строки по ~40px
- Идеально для экрана настроек, где много опций помимо темы
- Поповер/шторка — стандартный паттерн, не требует обучения
- Сетка в поповере может быть крупнее (больше места), чем встроенная
- На десктопе поповер не перекрывает весь интерфейс — видно результат выбора
- Хорошо комбинируется с другими настройками (контраст, стиль фильтра)
  в одном экране

### Минусы
- На один клик больше: открыть поповер → выбрать тему (против 1 тапа в сетке)
- Пользователь может не заметить, что слот кликабелен (нужен hint:
  стрелка ▸ + cursor:pointer)
- Поповер на десктопе требует аккуратного позиционирования (не вылезти за экран)
- Шторка на мобильном скрывает контент — пользователь не видит,
  как тема применяется к странице *под* шторкой (решается прозрачным фоном
  шторки или мгновенным применением)
- Нужно два поповера/шторки для двух групп — не открыть одновременно

### Accessibility-заметки
- Слот: `role="button"`, `aria-haspopup="listbox"`, `aria-expanded="true/false"`
- При открытии поповера — фокус переносится на выбранную карточку
- При закрытии (Esc / тап вне) — фокус возвращается на слот
- Внутри поповера: стрелки ← ↑ → ↓ перемещают фокус по карточкам
- Шторка на мобильном: `role="dialog"`, `aria-label="Выбор светлой темы"`,
  фокус-ловушка (focus trap)
- Свотч в слоте — декоративный, информация дублируется текстом

## Сравнение вариантов A и B

| Критерий | Вариант A: Карусель с текстом | Вариант B: Слоты + поповер |
|----------|:---:|:---:|
| **Скорость выбора (1 тема)** | ★★★★ (свайп + тап) | ★★★ (тап по слоту + тап по карточке) |
| **Скорость сравнения тем** | ★★★ (листать по одной) | ★★★★★ (видно все сразу в сетке) |
| **Информативность превью** | ★★★★★ (живой текст) | ★★★ (цветовые квадратики) |
| **Компактность** | ★★ (300px+) | ★★★★★ (80px в свёрнутом виде) |
| **Мобильный UX** | ★★★★★ (свайп естественен) | ★★★★ (шторка — Ok, но лишний шаг) |
| **Десктопный UX** | ★★★ (стрелки — не очень) | ★★★★★ (поповер — идеально) |
| **Сложность реализации** | ★★★★ | ★★★ |
| **WOW-эффект** | ★★★★★ | ★★★ |
| **Уместность среди других настроек** | ★★ (доминирует) | ★★★★★ (не перетягивает внимание) |
| **Подходит для частой смены темы** | ★★★★★ | ★★★ |

## Рекомендация по применению

| Сценарий | Вариант |
|----------|---------|
| **Экран настроек** (тема — одна из 5–10 опций) | **B (слоты + поповер)** — компактно, не доминирует |
| **Быстрая смена темы из шапки** (рядом с другими селектами) | **B (слоты + поповер)** — 40px высоты, как текущий `<select>` |
| **Onboarding / первый запуск** («выберите тему для чтения») | **A (карусель с текстом)** — эффектно, информативно |
| **Отдельная страница «Темы»** | **A (карусель)** — когда тема — главный герой экрана |
| **Планшет / десктоп** | **B (поповер)** — не перекрывает контент |
| **Телефон (частый пользователь)** | **A (карусель)** — быстрее переключаться |

### Комбинированный подход (best of both)
В шапке `canvas-header` — **Вариант B** (компактные слоты).
При первом запуске — onboarding-экран с **Вариантом A** (карусель с живым текстом),
где пользователь один раз выбирает свои светлую и тёмную темы.
После этого в шапке видит слоты с текущим выбором и может сменить через поповер.
