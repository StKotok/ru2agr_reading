После каждой задачи: тесты зелёные, ручная проверка пройдена, коммит сделан.

**Цель:** превратить текущий конвертер «Russian → Ancient Greek Trainer» в спокойную библейскую читалку Нового Завета с регулируемым греческим слоем: сначала подмешиваются греческие буквы, потом слова из личного словаря, потом реальные формы оригинала.

**Архитектура:** та же философия, что у текущего проекта — vanilla JS (ES-модули) без фреймворка, PWA, offline-first, IndexedDB. Добавляются: слоистый движок рендеринга греческого, pub/sub-стор, hash-роутер, статические JSON-данные текстов, пайплайн их подготовки на Node и Vite как сборщик (dev-сервер с HMR, один минифицированный бандл в проде, service worker генерируется vite-plugin-pwa).

**Стек:** vanilla JS (ES modules, без фреймворка), Vite + vite-plugin-pwa, CSS custom properties, IndexedDB, Service Worker. Dev-зависимости: Node 20+, Vitest. Деплой — статика из `dist/` (GitHub Pages или аналог).

## 1. Видение продукта

Это **не учебник и не словарь, а библейская читалка с обучающим греческим слоем**. Пользователь читает Новый Завет как обычно, а греческий постепенно «просвечивает» внутри текста: сначала буквы, потом слова, потом формы оригинала.

Краткая формула интерфейса: *спокойная библейская читалка с регулируемым греческим слоем; на десктопе чтение дополняется боковым инспектором слова, на мобильном подсказки открываются нижней карточкой по тапу.*

**Педагогический контракт.** Приложение учит *узнавать* буквы, частотные слова и формы НЗ в процессе чтения — оно не является курсом грамматики или перевода и не обещает «выучить греческий». Режимы 1–3 — **учебный мостик** (подстановки в русском тексте, искусственный приём), режимы 4–5 — **приближение к оригиналу** (реальный греческий текст); это различие проговаривается в интерфейсе, чтобы пользователь не принимал буквенные подстановки за оригинал. Произносительная модель — простое учебное приближение для русскоязычного новичка (эразмово чтение), а не строгая фонетическая реконструкция.

Главные разделы приложения:

1. **Чтение** — основной экран.
2. **Словарь** — слова, которые пользователь учит.
3. **Прогресс** — освоенные буквы, слова, главы.
4. **Настройки обучения** — уровень и интенсивность греческого.

## 3. Целевая архитектура

### 3.1 Принципы

1. **Без фреймворка, но со сборщиком.** Код — vanilla JS, никаких React/Vue. Vite даёт dev-сервер с HMR и один минифицированный бандл в проде (нативная загрузка десятков мелких ES-модулей — сетевой waterfall на холодном старте); vite-plugin-pwa генерирует service worker из манифеста сборки, избавляя от ручного precache-списка.
2. **Движок отделён от UI.** Всё, что превращает текст в «текст с греческим слоем», — чистые функции без DOM, покрытые тестами. UI только рендерит сегменты.
3. **Детерминированность.** Один и тот же текст + одни и те же настройки → одинаковый результат. Случайность — через хеш от позиции, а не `Math.random()`.
4. **Данные — статические JSON по книгам.** Грузятся лениво (`fetch`), кешируются service worker'ом. Никакого бэкенда.
5. **Состояние пользователя — IndexedDB.** Настройки, прогресс, словарь. Никаких аккаунтов в MVP.
6. **Слои кумулятивны.** Буквенный слой работает во всех режимах 1–4; словарный/формовый слой добавляется поверх; режим 5 переключает основной язык.
7. **Ручное управление обучением.** Никакой «умной» адаптации: приложение не считает клики, открытия подсказок и ошибки. Пользователь сам регулирует интенсивность, количество букв и слов, режим и статусы «знаю» — понятными ручными лимитами.
8. **Минимум перерендеров.** Полный перерендер отрендеренных глав — только когда меняется картина замен (режим, интенсивность, состав введённых букв, состав/настройки слов). Всё остальное (подсветка статуса, выделение выбранного слова) — точечные мутации классов через `querySelectorAll('[data-lexeme="…"]')`, без сноса DOM: иначе ломаются выделение текста, фокус и появляются микро-моргания.

        { "w": "ἀρχῇ", "lemma": "ἀρχή", "morph": "N-DSF", "strong": 746 }

```json
{ "id": "john", "verses": { "1:1": [ { "ru": 3, "gr": 5 } ] } }
```

**Алфавит** — `data/alphabet.json`:

```json
[
  {
    "lower": "α", "upper": "Α", "name": "альфа", "translit": "a",
    "sound": "читается примерно как «а»",
    "ruEquivalents": ["а"], "learnOrder": 1
  }

```

`learnOrder` — педагогический порядок введения (сначала визуально знакомые: α ο κ μ τ ε ι ν…, потом θ χ φ η ω ψ ξ).

**Базовый лексикон** — `data/lexicon/core.json`:

```json
[
  {
    "id": "logos", "lemma": "λόγος", "translit": "logos", "strong": 3056,
    "gloss": "слово, речь, смысл",

    "ruMatches": ["(?<![а-яё])слов(о|а|у|е|ом|ах|ами)(?![а-яё])"],

```

`ruMatches` — вручную выверенные регулярки по русским основам (MVP 2, до выравнивания); `ruExclude` — стоп-слова против ложных срабатываний. В MVP 3 замены переходят на выравнивание, `ruMatches` остаются fallback'ом.

```js

```

### 3.4 Движок греческого слоя

Режим определяет, какие слои включены. Режимы 1–3 — «учебный мостик» (подстановки в русском тексте), 4–5 — «приближение к оригиналу» (реальный греческий текст); группировка видна в селекторе режима и настройках.

| Режим | Группа | Название | Слои |
|---|---|---|---|
| 1 | мостик | Только греческие буквы | letter-layer |
| 2 | мостик | Буквы + подсказки | letter-layer + интерактивные подсказки по букве |
| 3 | мостик | Слова из моего словаря | word-layer (леммы) → letter-layer на остальном тексте |
| 4 | оригинал | Реальные формы оригинала | form-layer (по выравниванию) → letter-layer на остальном |
| 5 | оригинал | Почти оригинал | греческий текст основной, русский — подстрочной подсказкой |

`compose.js` — единственная точка входа для UI:

```js
// ctx: { mode, intensity, alphabetProgress, dictionary, lexicon, alignment?, grcVerse?, seedPrefix }
composeVerse(verseText, ctx) → Segment[]
```

Порядок применения: сначала словарный/формовый слой размечает диапазоны слов, затем буквенный слой обрабатывает оставшийся plain-текст. Буквенный слой заменяет **только введённые буквы** (status `learning`/`known` в `progress.letters`); вероятность замены каждого вхождения — детерминированная: `hash01(seedPrefix + ':' + позиция + ':' + правило) * 100 < intensity`. `seedPrefix` = id книги — при изменении настроек картина замен меняется предсказуемо, при скролле и перерендере — стабильна.

### 3.6 Состояние и реактивность

`src/state/store.js` — минимальный pub/sub:

```js
const store = createStore(initialState);
store.get();                    // текущее состояние
store.update(s => ({ ...s, intensity: 50 }));
store.subscribe(['settings'], (state) => rerender());  // подписка по ключам
```

Политика обновлений (принцип 8 из 3.1): изменение режима, интенсивности, состава букв или слов → перерендер отрендеренного окна глав с сохранением позиции скролла; всё, что не меняет картину замен (статус «знаю», подсветка), → точечные мутации классов (`querySelectorAll('span.gr[data-lexeme="logos"]')`) без перерендера. Запись в IndexedDB — с дебаунсом 300–500 мс (паттерн уже есть в `ui.js`).

### 3.7 UI-слой

- **Роутер** — hash-навигация: `#/read/john`, `#/dictionary`, `#/progress`, `#/settings`, `#/onboarding`. Экран = модуль с `mount(container, ctx)` / `unmount()`.
- **Адаптивность** — одна вёрстка, переключение по `@media (min-width: 900px)`: на десктопе три колонки (навигация | текст | инспектор), на мобильном — текст во весь экран + нижняя навигация + bottom sheet.
- **`word-card.js` один для всех** — и инспектор (десктоп), и bottom sheet (мобайл) рендерят одну и ту же карточку.
- **Ленивый рендер с DOM-окном** — книга остаётся одной непрерывной лентой (продуктовое требование), но в DOM живёт только окно глав вокруг вьюпорта (~±3 главы): новые главы дорендериваются по `IntersectionObserver`, а ушедшие далеко за экран сворачиваются в пустой `<div>` с зафиксированной измеренной высотой, чтобы скролл не прыгал (у Луки ~25 000 слов — держать все span'ы в DOM нельзя).
- **Sticky-заголовок главы** — заголовок текущей главы («Ин 1») закреплён при прокрутке, чтобы не теряться в склеенной книге.

## 4. Функциональная спецификация

### 4.1 Экран чтения

**Desktop (≥900px)** — три колонки:

```text
┌──────────────┬──────────────────────────────┬────────────────────┐
│ Навигация    │ Текст Нового Завета           │ Инспектор слова    │
│ Иоанна 1     │ В начале был ὁ λόγος...       │ λόγος              │
│ Иоанна 2     │                              │ logos              │
│ Словарь      │                              │ слово, речь, смысл │
│ Прогресс     │                              │ Лемма: λόγος       │
│ Настройки    │                              │ [Я знаю]           │
└──────────────┴──────────────────────────────┴────────────────────┘
```

Левая панель: книги/главы, последнее место чтения, ссылки на разделы; сворачивается. Центр: текст книги **целиком** (все главы склеены подряд, с заголовками «Глава N»). Греческие вставки заметны, но мягко: спокойный цвет, без ощущения ошибки. Правая панель: инспектор выбранной буквы/слова.

**Mobile** — текст во весь экран:

```text
┌──────────────────────────────┐
│ Ин. 1 ▼        Уровень 2 35% │
├──────────────────────────────┤
│ В начале был ὁ λόγος, и      │
│ ὁ λόγος был у Бога...        │
├──────────────────────────────┤
│ Читать | Слова | Прогресс | ⚙ │
└──────────────────────────────┘
```

Тап по слову → bottom sheet с карточкой. Заголовок текущей главы — sticky: при прокрутке всегда видно, где находишься.

Позиция чтения (книга + прокрутка) сохраняется и восстанавливается при следующем запуске.

У экрана есть явные состояния: загрузка книги (скелетон), оффлайн без кеша («Эта книга ещё не загружалась — нужен интернет» + «Повторить»), недоступность данных греческого слоя (деградация в режим 3 + тост).

### 4.2 Регулятор «доза греческого»

Не переключатель, а регулятор насыщенности + пять режимов (таблица в 3.4):

```text
Греческий в тексте: 35%
[────●────────────]
```

Интенсивность управляет долей заменяемых вхождений букв; у слов — своя пер-словная интенсивность. Верхняя панель: `[Иоанна 1 ▼] [Режим 2 ▼] [Греческий 35%] [⚙]` (десктоп), `Ин. 1 ▼  35% ⚙` (мобайл). Выбор перевода появится в панели, когда переводов станет больше одного (бэклог).

### 4.3 Карточка слова / буквы

**Карточка буквы** (режимы 1–2): буква, имя («альфа»), как читается, русское соответствие, кнопка **[Я знаю эту букву]**. Внизу мелкая оговорка: произношение — учебное приближение, не научная реконструкция.

**Короткая карточка слова** (MVP 2):

```text
λόγος
logos
слово, речь, смысл
Сейчас заменяет: «Слово»
[Подробнее] [Я знаю]
```

Если слова нет в личном словаре (тап по токену в режиме 5, слово из врезки главы) — вместо [Я знаю] кнопка **[Добавить в словарь]**. Добавление слов происходит только кнопками в карточках и врезках, не жестами.

**Подробная карточка** (MVP 3): + словарная форма, форма в тексте, грамматика по-русски («существительное, муж. род, им. падеж, ед. число»), блок «Формы в НЗ» — реальные формы слова, встречающиеся в греческом тексте (λόγος, λόγον, λόγου, λόγῳ — с подписями падежей), другие места употребления — клик открывает всплывашку с текстом стиха и кнопкой «Перейти», статус (Новое/Учу/Знаю), Strong number — спрятан в «дополнительно».

### 4.4 Личный словарь

Центр управления словами, которые появляются в тексте. Фильтры `[Все] [Новые] [Учу] [Знаю]`, список «λόγος — слово, речь». У каждого слова: статус, «показывать в тексте: да/нет», интенсивность (часто/иногда/редко), формы (только лемма / все формы). В тексте заменяются **только слова из личного словаря**.

### 4.5 Прогресс

Не «12% курса», а карта освоения: буквы (освоены / в процессе), слова (знакомы / в изучении / новых сегодня), чтение (какие книги/главы прочитаны). Плюс мотивирующая строка: `Ты уже узнаёшь: α ο ε ι κ μ ν τ λόγος θεός ζωή`.

### 4.6 Настройки обучения

Режим (5 радио-пунктов из 3.4, сгруппированы: «Учебный мостик» 1–3 / «Ближе к оригиналу» 4–5), интенсивность, новых слов за главу (1/3/5/10), переключатель «Сегодня не добавлять новое», чекбоксы: транслитерация, краткое значение, грамматика, ударения и придыхания, Strong numbers (в «дополнительно»). Плюс тема (светлая/тёмная/авто). Всё управление обучением — ручное (принцип 7 из 3.1): никакого скрытого подсчёта кликов и «умной» адаптации.

### 4.7 Онбординг

Первый запуск. Вопрос — про намерение пользователя, а не экзамен уровня:

```text
Что тебе ближе?
1. Хочу читать почти по-русски и привыкать к буквам  → режим 1, вводятся 3 буквы (α ο κ)
2. Знаю часть букв, хочу видеть больше греческого    → режим 2, введены первые 8 букв
3. Хочу узнавать греческие слова                     → режим 3, все буквы known
4. Хочу читать ближе к оригиналу                     → режим 4 (до MVP 3 — режим 3), все буквы known
```

Второй шаг — «С чего начнём чтение?»: **Иоанн 1** (классический старт — «В начале было Слово», идеальная сцена для первого греческого слова λόγος), **Марк 1** (самое короткое Евангелие) или **Продолжить с последнего места** (только если прогресс уже есть). После выбора открывается текст и тост: «Сегодня добавим 3 буквы: α = а, ο = о, κ = к. Читай как обычно. При нажатии увидишь подсказку» (для варианта 1).

### 4.8 Не ломать чтение

- Кнопка **[Показать обычный русский текст]** — мгновенно выключает слой (toggle, настройки не сбрасывает).
- Hover (десктоп) / одиночный тап (мобайл) по греческой вставке — карточка. «Я знаю» и «Добавить в словарь» — кнопками **внутри карточки**, не жестами.
- Долгий тап по греческой вставке — временно показать русский вариант (на `.gr` стоит `user-select: none`, чтобы не конфликтовать с системным выделением текста).
- Свайп вниз — закрыть bottom sheet.
- Двойной тап **сознательно не используется**: он конфликтует с системными жестами и делает одиночный тап «ватным» (ожидание ~300 мс).

### 4.9 Визуальный стиль

Светлая спокойная библейская читалка. Палитра задаётся **токенами ролей**, а не «цветами»: `--surface` (фон, тёплый белый `#FAF7F2`), `--surface-card` (карточки, светло-бежевый), `--text` (тёмно-графитовый `#2B2B2B`), `--muted` (вторичный текст), `--greek` (греческие вставки, спокойный синий `#3D5A80`), `--hint` (подсказки/подчёркивания), `--focus` (видимое кольцо фокуса), `--selection` (выбранное слово), `--progress` (мягкий зелёный/золотой), `--danger` (сброс прогресса), `--border`. Следить, чтобы интерфейс не стал однотонно-бежевым: акценты `--greek`/`--progress` обязаны давать живой контраст. Тёмная тема — те же роли, другие значения.

Шрифты — две роли: **текст Писания** — **Gentium Plus** (SIL OFL: кириллица-serif + политонический греческий, self-hosted woff2 для оффлайна); **интерфейс** (кнопки, меню, карточки, настройки) — системный sans-стек (`system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`). Контраст «книга/инструмент» — как в Apple Books. Мобильный текст: ≥18px, line-height ≥1.7.
